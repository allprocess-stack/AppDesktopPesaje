# BlzSoftTerminal

Terminal de pesaje desarrollado en C# .NET Framework 4.7.2 (Windows Forms) con conexión a base de datos MySQL.

## Descripción

Aplicación de escritorio para gestión de pesaje de vehículos. Permite registrar el peso de camiones con identificación manual o automática, manejo de tickets y consulta de históricos.

## Funcionalidades

- Login de usuario
- Pesaje de entrada y salida de vehículos
- Identificación manual de vehículos (vManualId)
- Conexión a base de datos MySQL
- Prevención de múltiples instancias

## Requisitos

- Windows 7 o superior
- .NET Framework 4.7.2
- MySQL Server

## Instalación

1. Clonar el repositorio `https://github.com/allprocess-stack/AppDesktopPesaje.git`
2. Abrir `BlzSoftTerminal.sln` en Visual Studio 2019 o superior
3. Restaurar paquetes NuGet
4. Compilar la solución
5. Configurar la cadena de conexión en `App.config`

## Tecnologías

- C# / .NET Framework 4.7.2
- Windows Forms
- MySQL (MySql.Data)
- Protobuf, ZstdSharp, BouncyCastle
